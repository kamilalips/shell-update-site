Verify authenticity of Shell in air gapped mode

Air-gapped verification needs no server and no network, only the list of produced devices has to be downloaded in advance.

This page helps you download the updater app and the latest produced units list for an offline verification of your Keycard Shell.

1.  Download stand-alone Shell updater app

The standalone updater app verifies your Shell without using internet or a web-browser. Pick the operating system of the offline machine and the button below downloads the latest release built for it from the app's GitHub repository.
Download Shell Updater
View changelog
•  File:
Check the updater's SHA256 checksum here. You can for instance use shasum -a 256 to validate the file you downloaded.
Copy the updater app to a freshly formatted USB stick. To avoid hidden malware, always format the USB drive before transferring files.

2.  Download produced units list

You can find Keycard Shell produced units list on the official GitHub repository, or download the latest list below.
Download produced units list
Check the integrity using SHA256 checksum.
•  SHA256:
Copy the units file to the same USB drive.

3.  Prepare offline device

Install a clean OS on an empty hard drive or external boot disk. This could be:
  • Your current machine (dual-boot or temp clean install)
  • A secondary dedicated device
Ensure it’s fully offline. Disconnect all other drives and physically disable Wi-Fi/Bluetooth if possible. Unlike an update, a verification also needs a working camera on that machine — it reads the answer your Shell shows on its screen.

4.  Run standalone app and pick the units file

Boot your offline machine and launch the app.
Choose "Verify Shell authenticity", set the units list to "From file", and pick the file off the USB drive.

5.  Scan the challenge, then the answer

Go to Settings/Shell/Verify on the Shell and scan the code on the screen.
The Shell answers with a QR code of its own — scan it with the camera you just enabled.
The challenge is made on the spot, so a response cannot have been recorded earlier. Nothing left either machine: the list, the challenge and the answer stayed on the two devices in front of you.
